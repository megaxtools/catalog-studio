# آزمون، انتشار نسخه و نقشه‌ی راه

## اجرا

```bash
pip install -r requirements.txt && python -m playwright install chromium
python -m studio                 # http://127.0.0.1:8765   (--no-browser)
python mcp_server.py             # MCP روی stdio
```

متغیرهای محیطی: `CATALOG_STUDIO_DATA` (پوشه‌ی داده)، `CATALOG_STUDIO_PORT`، `CATALOG_STUDIO_HOST`.

| `tests/e2e_features.py` | AI، قواعد متن، صف |
| `tests/e2e_mcp.py` | MCP روی stdio، HTTP و SSE |
| `tests/e2e_ai13.py`، `e2e_align14.py`، `e2e_ai15.py` | دستیار، ترازبندی، تولید ستون‌ها |
| `tests/e2e_catalog16.py` | توقف AI، ثبت همه‌چیز، خروجی‌های نسخه‌ی ۱.۶ |
| `tests/e2e_defaults161.py` | مقدار پیش‌فرض ستون‌ها |
| **`tests/e2e_ref21.py`** | قالب و نمونه‌ی ورود هر بخش، ورود داده‌ی خام از فایل و نگاشت ستون، درخت دسته و دسته‌های برند، عملیات گروهی، خروجی، AI در برند/دسته/الگو/تکراری، MCP |
| **`tests/e2e_v2.py`** | ماژول‌ها و دروازه‌ها، داده‌ی مرجع، خودروها و سازگاری، بانک تمیز، ویرایش و ریویژن، تصاویر و ویرایشگر تصویر، کیفیت، گروهی، AI، تکراری، الگو، کاتالوگ، انتشار و diff، اسکیماها، انتقال از نسخه‌ی ۱، پشتیبان، MCP |

```bash
for t in e2e e2e_features e2e_mcp e2e_ai13 e2e_align14 e2e_ai15 e2e_catalog16 e2e_defaults161 e2e_v2 e2e_ref21; do python tests/$t.py || break; done
```

- هر تست پوشه‌ی داده‌ی خودش را در `/tmp/cs-*` می‌سازد.
- `tests/fixture_site.py` روی پورت ۸۸۹۹ فروشگاه ساختگی و سرویس AI ساختگی را فراهم می‌کند. **هیچ‌وقت دو تست را هم‌زمان اجرا نکنید.**
- آزمون رابط با Playwright انجام می‌شود: همه‌ی صفحه‌ها بدون خطای کنسول باز شوند، و کشوی محصول، ویرایشگر تصویر و انتخابگر سازگاری کار کنند.

## انتشار نسخه

1. `VERSION` در `config.py` و `SERVER_VERSION` در `mcp_core.py` را بالا ببرید.
2. همه‌ی آزمون‌ها سبز باشند.
3. بخش «تازه‌های نسخه» در README، و در صورت نیاز `docs/guide` و `docs/design`، به‌روز شوند.
4. **مهاجرت فقط افزایشی:** هر تغییر ساختار یک نسخه‌ی مهاجرت تازه در ماژول مربوط است و هیچ داده‌ای حذف نمی‌شود.

## نقشه‌ی راه (پیشنهادی برای نسخه‌های بعد، در Claude Code)

- **ورود کاربران و نقش‌ها:**
  - ورود اپراتورها، محدودیت دسترسی بر اساس نقش (طرح در «کاربران و نقش‌ها»)، و صف کار هر اپراتور.
  - چندکاربره شدن احتمالاً با اجرای استودیو روی سرور و انتقال پایگاه داده به PostgreSQL انجام می‌شود.
- **ویرایشگر تصویر با AI:**
  - حذف هوشمند المان (inpainting) با مدل‌های ویرایش تصویر.
  - بهبود کیفیت (upscale).
  - یکسان‌سازی نور و رنگ گروهی.
- **ویرایشگر ویدیو** به‌صورت ماژول (`vid_*`)، طبق [راهنمای ساخت ماژول](02-modules.md).
- **انتشار مستقیم در مگا کارز:** ماژول ارسال انتشار با API پنل مگا کارز و پیگیری وضعیت هر محصول.
- **پاک‌سازی فایل‌ها:** حذف تصاویر بی‌استفاده‌ای که در هیچ نسخه‌ای ارجاع ندارند.
- **فهرست‌های مرجع رسمی:** همگام‌سازی برندها و دسته‌های مگا کارز از پنل.
