# الگوها و اسکیماها

همه‌ی تعریف‌های ساختاری استودیو در یک بخش است:

- **اسکیماها:** کدام ستون‌ها وجود دارند.
- **الگوهای خروجی:** چه فایل‌هایی در کدام پوشه ساخته شوند.
- **قواعد متن و فیلتر:** پاک‌سازی خودکار متن.
- **نگاشت برند و دسته:** وصل کردن نام‌های منابع به اسلاگ‌های مگا کارز.

## اسکیما

اسکیما فهرست ستون‌هاست. **کاربرد** هر اسکیما مشخص است:

| کاربرد | کجا انتخاب می‌شود |
|---|---|
| عمومی | همه‌جا |
| استخراج و داده‌ی خام | هنگام استخراج |
| ویرایشگر داده‌ها | ستون‌هایی که در بانک تمیز ویرایش می‌شوند |
| کاتالوگ و خروجی | در خروجی‌های «الگوهای خروجی» |

در فهرست اسکیماها برای هر اسکیما **محل استفاده** هم نمایش داده می‌شود: چند بانک خام، چند بانک تمیز و کدام الگوها. اسکیمایی که در بانک تمیز یا الگو استفاده شده حذف نمی‌شود. هر ذخیره یک نسخه می‌سازد (دکمه‌ی «نسخه‌ها»).

### انواع ستون

| نوع مقدار | معنی |
|---|---|
| استخراجی | از داده‌ی منبع |
| دستی | در استودیو وارد می‌شود |
| هوش مصنوعی | فقط با هوش مصنوعی ساخته می‌شود |
| ثابت | یک مقدار برای همه |
| نگاشت | اسلاگ برند یا دسته از جدول نگاشت |
| **مرجع** | برند، دسته یا **خودروهای سازگار** از داده‌های مرجع (با انتخاب «مقدار خروجی»: اسلاگ، نام، نام انگلیسی یا شناسه؛ برای خودروها «قالب سازگاری») |
| خودکار | اسلاگ، لینک منبع، شناسه و … |

**نوع ورودی** شکل مقدار را تعیین می‌کند: متن کوتاه، متن بلند، بولت، گروه بولت‌ها، گروه کلید/مقدار، مشخصات، تصویر، چند تصویر، JSON، بله/خیر، عدد یا خودروها.

### مقدار پیش‌فرض

زیر هر ستون دکمه‌ی «پیش‌فرض» هست. برای متن‌هایی که برای همه‌ی محصولات یکی است، مثل بایدها و نبایدها یا شرایط خرید، یک بار این‌جا بنویسید. چهار حالت اعمال دارد:

- **اگر خالی بود**
- **همیشه همین**
- **افزودن به ابتدا**
- **افزودن به انتها**

### ستون‌های هسته در ویرایشگر

در بانک تمیز، این ستون‌ها به فیلدهای اصلی محصول وصل‌اند و در بالای کشوی محصول ویرایش می‌شوند:

- عنوان (`title`)
- اسلاگ (نوع خودکار، اسلاگ)
- برند و دسته (نگاشت یا مرجع)
- خودروهای سازگار
- تصاویر (شاخص و گالری)

## الگوی خروجی (درخت فایل)

در **الگوهای خروجی و درخت فایل** تعیین می‌کنید هر انتشار کاتالوگ چه فایل‌هایی داشته باشد. پیش‌نمایش درخت فایل کنار فرم به‌روز می‌شود و خطاها (مثلاً مسیر تکراری) نمایش داده می‌شوند.

- **پوشه‌ی هر انتشار:** مثلاً `{catalog}-r{release}`.
- **خروجی‌های داده:** هر خروجی این تنظیمات را دارد:
  - **نوع:** محصولات، برندها، دسته‌بندی‌ها، خودروهای سازگار یا جدول سازگاری محصول و خودرو.
  - **قالب:** JSON (آرایه)، Excel یا CSV.
  - **اسکیما:** برای خروجی محصولات.
  - **ستون‌ها:** برای بقیه‌ی انواع.
  - **مسیر:** مثلاً `data/products.json`.
  - اگر مسیر `{slug}` داشته باشد، مثلاً `products/{slug}.json`، برای هر محصول یک فایل JSON جدا ساخته می‌شود.
- **تصاویر:** این تنظیمات را دارد:
  - **مسیر و نام:** مثلاً `images/{brand_slug}/{slug}/{name}.{ext}`.
  - **نام تصویر شاخص:** مثلاً `feature`.
  - **نام گالری:** مثلاً `gallery_{n}`.
  - **کدام تصاویر:** شاخص و گالری، یا فقط شاخص.
  - **پیوند تصویر در فایل‌های داده:** مسیر نسبی، پیشوند CDN یا لینک منبع.
- **ZIP** و **شناسنامه‌ی انتشار**.

**طراحی با AI:** در صفحه‌ی الگو، دکمه‌ی **طراحی با AI** را بزنید و ساختار دلخواه را به زبان ساده بنویسید، مثلاً «برای هر محصول یک فایل JSON با عنوان و تصاویر، تصاویر در پوشه‌ی هر برند، و برندها در Excel». الگوی پیشنهادی در همین صفحه پر می‌شود و درخت فایلش را می‌بینید؛ تا «ذخیره‌ی الگو» را نزنید چیزی ذخیره نمی‌شود.

**خروجی برندها و دسته‌ها:** فایل برندها ستون `category_slugs` (دسته‌هایی که برند در آن‌ها نمایش داده می‌شود) و فایل دسته‌ها ستون `brand_slugs` (برندهای قابل نمایش در آن دسته، با ارث‌بری از والد و زیرشاخه‌ها) دارد.

نشانه‌ها:

| نشانه | معنی |
|---|---|
| `{catalog}` `{release}` `{date}` | شناسه‌ی کاتالوگ، شماره‌ی انتشار، تاریخ |
| `{slug}` `{uid}` `{id}` | محصول |
| `{brand_slug}` `{category_slug}` | برند و دسته‌ی محصول |
| `{name}` `{ext}` `{n}` | نام، پسوند و شماره‌ی تصویر |

نمونه‌ی خواسته‌شده: «تصاویر به همراه عنوان محصولات در یک JSON و برندها در Excel»:

```
{catalog}-r{release}/
├── data/products.json      ← اسکیمای «عنوان و تصاویر»
├── brands.xlsx             ← نوع «برندها»
└── images/{brand_slug}/{slug}/feature.png …
```

این الگو به‌صورت آماده با نام «عنوان و تصاویر + برندها» وجود دارد.
