# معماری استودیو (نسخه‌ی ۲)

## نمای کلی

استودیو یک برنامه‌ی محلی است: یک سرور HTTP پایتون (Starlette و uvicorn)، یک پایگاه داده‌ی SQLite (حالت WAL) و رابط وب تک‌صفحه‌ای فارسی. رابط با JavaScript خالص و ES modules نوشته شده و فرایند build ندارد. ایجنت‌ها از طریق MCP (stdio، HTTP یا SSE) به همان API وصل می‌شوند.

```
مرورگر (static/js) ──HTTP──►  web.route  ──►  api.py / api_v2.py / modules/*  ──►  سرویس‌ها  ──►  SQLite (data/studio.db)
ایجنت‌ها (MCP) ──────────────►  mcp_core.py (کلاینت همان HTTP API)                                   └─ فایل‌ها: data/workbench, output/
```

## جریان داده

```
            ┌──────────────┐        ┌────────────────────┐        ┌──────────────────────┐
منبع وب ──►│  داده‌ی خام   │──────►│  ویرایشگر (بانک تمیز) │──────►│ کاتالوگ ← انتشار (r1…) │──► فایل‌های مگا کارز
AI ───────►│ datasets/items│ ورود  │ wb_banks/wb_products │ انتخاب │ cat_* + الگوی خروجی   │
            └──────────────┘        └────────────────────┘        └──────────────────────┘
               تغییرناپذیر            نسخه‌دار (revisions)            تغییرناپذیر + diff
                                ▲ داده‌های مرجع: خودروها، برندها، دسته‌ها
```

1. **داده‌ی خام** (`datasets`، `items`): خروجی استخراج یا تولید AI. ستون `data` هرگز بازنویسی نمی‌شود. لایه‌های نسخه‌ی ۱ (`overrides`، `manual`، `ai`) برای سازگاری با گذشته باقی مانده‌اند.
2. **ورود به ویرایشگر** (`workbench.product_from_item`):
   - مقدار هر ستون اسکیمای ویرایش با `services.column_value` محاسبه می‌شود. قواعد متن، نگاشت، پیش‌فرض و لایه‌های نسخه‌ی ۱ هم اعمال می‌شوند.
   - برند و دسته با `refdata.resolve` به فهرست مرجع وصل می‌شوند.
   - سازگاری با `compat.suggest` پیشنهاد داده می‌شود.
   - تصاویر دانلود و پردازش می‌شوند.
   - ریویژن ۱ ثبت می‌شود.
3. **محصول تمیز** (`wb_products`):
   - **فیلدهای هسته:** `title`، `slug`، `brand_id`، `category_id`، `compat`، `images`، `status`.
   - **مقدار بقیه‌ی ستون‌ها:** در `values_json`.
   - **منبع خام:** در `sources`.
   - هر تغییر از `workbench._save` می‌گذرد. این تابع امتیاز کیفیت را محاسبه و ریویژن ثبت می‌کند.
4. **انتشار کاتالوگ** (`product_catalog.build`):
   - انتخاب محصولات و کپی تصاویر با الگوی مسیر.
   - نوشتن خروجی‌ها، `manifest.json` و ZIP.
   - ذخیره‌ی رکورد اصلی و شماره‌ی ریویژن هر محصول در `cat_release_items`.
   - محاسبه‌ی diff با انتشار قبلی.

## ستون‌ها و نقش‌های هسته

اسکیما مشترک است و یک ستون، بسته به `core_role(col)` در `workbench.py`، به فیلدهای هسته‌ی محصول وصل می‌شود:

| نقش | تشخیص |
|---|---|
| `title` | کلید `title` |
| `slug` | `kind=auto, generator=slug` |
| `brand` / `category` | `kind=mapping` یا `kind=ref, ref=brand/category` |
| `compat` | `input=vehicles` یا `kind=ref, ref=vehicles` |
| `feature` / `gallery` | `input=image` / `input=images` |

`workbench.product_value(p, col)` مقدار هر ستون را برای یک محصول تمیز می‌دهد: از فیلد هسته، از `values` یا از ثابت و پیش‌فرض اسکیما. در خروجی کاتالوگ، `catalogs.structured` نوع JSON را تعیین می‌کند و `services.expand_column` ستون‌های Excel و CSV را می‌سازد.

## اولویت مقدار

- **در داده‌ی خام (نسخه‌ی ۱):** ویرایش دستی ← ورود دستی ← پیش‌فرض «همیشه همین» ← AI ← داده‌ی استخراج‌شده (پس از قواعد متن) ← پیش‌فرض «اگر خالی بود / ابتدا / انتها».
- **در ویرایشگر:** مقدار ذخیره‌شده‌ی محصول تمیز ملاک است. پیش‌فرض اسکیما فقط هنگام خواندن و فقط برای مقدارهای خالی یا حالت‌های ابتدا و انتها اعمال می‌شود.

## فایل‌ها

| مسیر | محتوا |
|---|---|
| `data/studio.db` | پایگاه داده |
| `data/workbench/bank-<id>/<uid>/img-<n>_raw.*` | تصویر خام |
| `…/img-<n>_raw_rembg.png` | بدون پس‌زمینه (میانی، قابل استفاده‌ی دوباره) |

| `data/backups/` | پشتیبان‌ها |

## اصول طراحی

- **افزایشی و برگشت‌پذیر:** داده‌ی خام تغییر نمی‌کند، هر تغییر نسخه دارد و انتشارها تغییرناپذیرند.
- **فهرست‌های کنترل‌شده:** برند، دسته و خودرو فقط از داده‌ی مرجع انتخاب می‌شوند و اسلاگ‌ها انگلیسی‌اند.
- **ماژولار:** هر قابلیت جانبی قابل خاموش کردن است و خطای یک ماژول بقیه را از کار نمی‌اندازد. [ماژول‌ها](02-modules.md) را ببینید.
- **سه مسیر یکسان:** هر قابلیت از رابط، API و MCP در دسترس است.
- **فارسی و RTL:** متن‌های رابط و پیام‌های خطا فارسی‌اند. در محتوای محصولات «کسب‌وکار» نوشته می‌شود (نه «شعبه»)، و قیمت یا نام رقبا نمی‌آید.
